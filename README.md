
# 🌤️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript**.  
The app uses a weather API to fetch real-time weather information for a searched city.

This project was built as my first project involving **JavaScript, APIs, asynchronous requests, and dynamic DOM manipulation**.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- 💧 Display humidity
- 💨 Display wind speed
- ☁️ Display current weather condition
- 📱 Responsive design
- ⚠️ Handles invalid city searches and API errors
